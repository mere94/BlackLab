# Black Lab Hair Spa

A modern React + TypeScript + Vite web application for **Black Lab Hair Spa** located in Corso Casale 205/I, Torino.

## Features

- **Personalized Hair Care Showcase**: Four core service areas — Hair Care, Colore, Disciplina, and Hair Spa — with detailed consultation breakdowns and direct booking links.
- **Brand Story & Salon Philosophy**: Introduction to the salon's diagnosis-first methodology (*"Prima i tuoi capelli. Poi tutto il resto."*).
- **Interactive Visual Gallery**: High-resolution showcase of the studio environment, styling stations, and professional products with an accessible modal lightbox.
- **Direct Appointments & Consultation**: One-click booking via Bewelly platform and instant direct messaging on WhatsApp.
- **Studio Schedule & Google Maps Location**: Up-to-date weekly business hours and directions to Corso Casale 205/I, Torino.
- **GDPR Compliance**: Cookie consent banner with persistence and dedicated modal views for Privacy Policy and Cookie Policy.
- **Accessibility & Responsiveness**: Mobile navigation menu with keyboard controls (Escape key support), skip link, and sticky mobile booking bar.

## Tech Stack

- **Framework**: React 19 with TypeScript
- **Bundler & Dev Server**: Vite
- **Styling**: Tailwind CSS & Custom Design Tokens
- **Icons**: Lucide React
- **Fonts**: Cormorant Garamond & Manrope

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
